# Site institucional Orbey

Site responsivo estático, pronto para GitHub Pages.

## Antes de publicar
1. Abra `script.js`.
2. Substitua `5500000000000` em `ORBEY_WHATSAPP` pelo número comercial, com código do país e DDD, somente dígitos. Exemplo de formato: `5585999999999`.
3. Revise textos, serviços, links e identidade visual conforme necessário.

## Publicar gratuitamente no GitHub Pages
1. Entre em https://github.com e crie um repositório público chamado `orbey-site`.
2. Envie os três arquivos (`index.html`, `styles.css`, `script.js`) para a raiz do repositório.
3. No repositório, entre em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha `main` e `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço será semelhante a `https://SEU-USUARIO.github.io/orbey-site/`.

## Formulário
O formulário valida os campos no navegador e abre o WhatsApp com uma mensagem pré-preenchida. O visitante precisa revisar e enviar a mensagem. Nenhum dado é guardado ou enviado automaticamente pelo site. Para um formulário que envie e-mails diretamente sem WhatsApp, será necessário conectar um serviço de formulários ou backend.

## Observações
- Fontes DM Sans e Manrope são carregadas do Google Fonts; há fontes alternativas caso não carreguem.
- As fotografias de destaque vêm do Unsplash e precisam de internet para carregar.
- O símbolo do capacete é uma marcação vetorial temporária estilizada; substitua pelo arquivo oficial do logotipo Orbey quando disponível.
